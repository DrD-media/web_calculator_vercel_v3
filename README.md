# web_calculator_vercel_v3
web_calculator_vercel
Web Calculator: ISO 9126 / ISO 25010 Software Quality System Dynamics (Subtree U5)
Interactive numerical simulation of software maintainability dynamics using a 28-variable nonlinear ODE system solved with the Runge-Kutta 4th order (RK4) method.
Features
100% Client-side: Zero backend setup, pure HTML5, CSS, and vanilla JavaScript.
Runge-Kutta 4th Order Solver: 28 ODE equations, 187 polynomial coupling functions, 6 external perturbation factors $\lambda_1(t)..\lambda_6(t)$.
Filtering & Analysis:
Perturbation curves with isolation filters.
Characteristics with single-variable isolated inspection mode and multi-variable comparison.
Quarterly polar radar charts ($t = 0.0, 0.25, 0.50, 0.75, 1.00$).
Export: In-browser CSV/Excel data generation and high-res PNG chart downloads.
Academic Theme: Strict, neutral university design without emojis or casual slang.
Deployment to Vercel
Simply drag and drop this folder into the Vercel dashboard at vercel.com/new.
